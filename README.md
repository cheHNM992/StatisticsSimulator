# アンケート・バイアスシミュレータ

対象者と非対象者の回答しやすさの違いによって、回答者の構成が母集団から
どの程度ずれるかを確認するStreamlitアプリです。
各人の対象者・回答有無をNumPyの乱数で決めるため、実行ごとに結果は変わります。

## 必要環境・インストール

Python 3.11以上が必要です。仮想環境の利用を推奨します。

```bash
python -m venv .venv
```

Windows（PowerShell）では `.venv\Scripts\Activate.ps1`、
macOS / Linuxでは `source .venv/bin/activate` で有効化します。

```bash
python -m pip install -r requirements.txt
```

グラフの日本語表示には、フォントを同梱した
[matplotlib-fontja](https://pypi.org/project/matplotlib-fontja/1.1.0/)を使用します。
同梱フォントの利用にはIPAフォントライセンスが適用されます。

## 起動方法・使い方

```bash
streamlit run app.py
```

ブラウザで母集団人数、対象者割合、対象者・非対象者それぞれの回答率を設定し、
「シミュレーション実行」を押してください。
母集団と回答者の対象者割合、全体の回答率、母集団との差（pt）、回答者数を表示します。
母集団割合は設定値ではなく、実際に生成された母集団から計算します。
回答者がいる場合は、対象者割合を0～100%の棒グラフで比較できます。

初回は結果を表示しません。結果は次の実行まで保持され、
入力を変更すると消去されて再実行を案内します。
回答者が0人の場合は警告を表示し、観測割合と差は「算出不可」となります。

### 取りうる値の逆算

「取りうる値の逆算」タブで、母集団人数・回答者数・回答者に占める対象者割合を
入力し、「取りうる値を表示」を押してください。母集団の対象者割合は入力不要です。
横軸に母集団の対象者割合、縦軸に対象者・非対象者の回答率を表示し、
3項目それぞれの最小値・最大値と全体の回答率を併記します。

回答者内の割合は小数点以下1桁の表示値として扱い、その表示になる整数の
対象者回答人数をすべて候補にします。候補が複数ある場合は人数範囲・候補数を
表示し、グラフの系列を薄く重ねます。各候補について、回答人数以上の人数を
各群に割り当てられる母集団構成だけを計算します。
3項目の範囲内の値を自由に組み合わせられるわけではありません。
回答率は各群の回答人数をその群の人数で割った値です。

回答者数が母集団人数を超える場合や、回答者数と表示割合が整合しない場合は
エラーを表示します。回答者0人では割合入力を無効にし、母集団割合0～100%と
存在する群の回答率0%を表示します。存在しない群の回答率は算出不可です。
全員回答で両群が存在する場合は、両群の回答率がともに100%になります。
各タブの結果は独立して保持され、そのタブの入力を変更すると消去されます。

## テスト

テストは標準ライブラリのunittestとStreamlitのAppTestを使います。
追加のテスト用パッケージは不要です。

```bash
python -m unittest discover -s tests -v
```

計算の境界値・回答率による傾向、グラフ、日本語フォント、
初回表示・再実行・結果保持・入力変更時の消去を確認します。
逆算についても、人数と丸めの整合性、取りうる範囲、分母0、
グラフ・結果保持・タブ間の独立性を確認します。
